## GitHub fork and attribution

The adaptation is intended for the genuine GitHub fork
[AurinVos/EnzyDesign-Lit](https://github.com/AurinVos/EnzyDesign-Lit),
created directly from `basvandervelden/ai_food_safety_review`.
The fork retains upstream Git commit ancestry and GitHub's fork relationship.
The project title "Enzyme Evidence Atlas" refers to the enzyme-specific website;
the destination repository is named `EnzyDesign-Lit`.

Publishing repository code is separate from enabling GitHub Pages or validating
an automated literature refresh. Deployment and live update status must be checked
in GitHub Actions; no successful deployment is implied by the existence of a fork.

## Publication rights

The software licence does not relicense publishers' articles, abstracts, figures or supplementary data. The seed provides bibliographic identifiers, abbreviated attribution, links and original concise summaries. No publisher figures, full-text articles or complete abstracts are bundled in the seed. Metadata imported later remains subject to its source terms. Do not publicly redistribute institutional full-text downloads without checking rights.
